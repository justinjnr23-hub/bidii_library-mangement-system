# Bidii library 
Bidii library is a digital library website is designed to make discovering and exploring books easier through an accessible online platform.

 ![License: MIT](https://img.shields.io/badge/license-MIT-green)
![HTML5](https://img.shields.io/badge/HTML5-semantic-e34f26?logo=html5&logoColor=white)

![bidii library Home Page](assets/book-library.jpg)
## Features
- Book Catalogue: Explore a collection of books organised into categories, making it easier to discover reading materials.

- has sign-in, registration and password-reset interfaces.

- has Contact Information: Find library contact details and an enquiry form
## Requirements
- modern browsers(chrome,edge,firefox)
- Vscode + live server extension
